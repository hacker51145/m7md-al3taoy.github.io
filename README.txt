- من قائمة المتصفح اختر "إضافة إلى الشاشة الرئيسية" أو "Install app".
- اسمح للمايك والإشعارات عند طلبها.

الموجود الآن:

- إملاء صوتي وقراءة الرد بصوت الجهاز (حسب دعم المتصفح).
- تذكيرات محفوظة على الجهاز.
- قابلية التثبيت كتطبيق PWA.

- الذكاء الاصطناعي الحقيقي غير مربوط بعد. يوجد مكان اتصال /api/chat لكنه يحتاج خادماً آمناً ومفتاح API.
- لا تضع مفتاح API داخل ملفات الموقع أو JavaScript العام.
- إشعارات الخلفية الموثوقة والمكالمات الهاتفية تحتاج خدمة خلفية ومزود اتصالات، وليست مفعّلة في هذه النسخة.
